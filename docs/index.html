What it does

Always one shortcut away

Double-tap ⌥ Option to show or hide Clod over any app. It lives in the menu bar, not the Dock.

Works with your files

Drag a folder onto Clod and Claude can read, organise and edit what's in it. Attach files, paste images or snap part of your screen.

You stay in control

In Ask mode, Claude checks with you before it changes a file or runs a command.

Picks up where you left off

Tabs for separate tasks, and past conversations you can search, pin and reopen.

Real Claude Code underneath

Clod runs Anthropic's own Claude Code, with the latest models, so it can do everything Claude Code can.

Private by design

No tracking or analytics. Your messages go to Anthropic, the same as using Claude Code directly.

Install in a few minutes

  1. Download Clod with the button above, open the file, and drag Clod into your Applications folder.
  2. Open Clod. Because Clod isn't from the App Store, macOS says it can't check it. Click Done.
  3. Open System Settings → Privacy & Security, scroll to the bottom, click Open Anyway next to "Clod was blocked", and enter your Mac password. You only do this once.
  4. Follow Clod's setup. It installs Claude Code, signs you in to Claude, and turns on the shortcut, explaining each step as it goes.

Why the warning? Apple charges developers to have apps checked, and Clod is a free personal project. The full source code is on GitHub for anyone to read.
